ArenaMW Mobile V13.7.16 — client-side improvements ported from ArenaMP 1.4.3/1.4.4

Ported to single-player:
- Mods screen no longer crashes if opened before selecting valid game resources.
- build.ini is saved after mod checkbox/order changes with 200 ms debounce and forced save on exit.
- build.ini save failures are shown to the user instead of failing silently on final save.
- StorageChooser/file manager gets RU/EN labels and Russian library strings.
- Launcher preparation/start/config-directory error messages are localized RU/EN.

Already present in single and therefore not duplicated:
- launcher icon transparent safe-zone / OEM crop protection (V13.7.15).

Not ported because they are ArenaMP-only:
- Android dedicated server UI/service/runtime and writable server folders.
- server start/stop checkbox, IP/port endpoint logic and complete=true network endpoint locking.
- server console/autoscroll/restart logic and TES3MP network identity fields.
