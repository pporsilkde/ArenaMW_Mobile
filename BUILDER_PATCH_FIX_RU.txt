ArenaMW Mobile builder patch reliability fix

1. Raw ExternalProject "patch -N" calls replaced by an idempotent helper.
2. Every third-party patch gets a checksum marker in its source tree, so CMake may rerun PATCH_COMMAND safely.
3. Helper accepts: apply now / already present / clean git 3-way merge.
4. ArenaMW engine patch driver accepts patches already merged upstream and harmless context drift.
5. If an old CI run left ArenaMW half-patched, the disposable source checkout is reset automatically.
6. If an engine patch really conflicts, the source is restored clean before exit, so the next cached run is not poisoned.
7. Patch 28 stable-shadows stays intentionally outside the active chain, matching the current builder revision that disabled it.
