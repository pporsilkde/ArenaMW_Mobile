ArenaMW Android — Graphics Profiles + Shadow Safe V16
Дата: 2026-08-14

Что изменено
============
1. Старый одиночный селектор графики удалён из главного экрана настроек.
2. Сразу под «Моды» добавлена кнопка «Настройки графики».
3. Кнопка открывает прокручиваемое окно с селекторами:
   - Общее качество
   - OSG / рендер
   - Дальность / предзагрузка
   - Ландшафт
   - Качество шейдеров
   - Освещение
   - Тени
   - Трава
4. Каждый раздел: Низкие / Средние / Высокие / Ультра.
5. Если изменить отдельный раздел, общий профиль становится «Пользовательские».
6. При первом запуске лаунчер один раз выбирает профиль автоматически по RAM,
   числу CPU-ядер и доступной версии GLES. Старые launcher-presets мигрируются.
7. Launcher profile записывается в settings.cfg только после первого автоподбора
   или после нажатия «Применить». На каждом следующем старте он НЕ перезаписывает
   ручные изменения, сделанные из меню самой игры.

Средняя база
============
Средний OSG оставлен близким к проверенной старой Android-базе:
- OSG threading: DrawThreadPerContext
- database/pager threads: 4 / 4
- compile threads: 2
- MaxPagedLOD: 6
- async physics: 2
- viewing distance: 5120
- preload distance: 1000
- preload threads: 2
- terrain lod factor: 0.65
- composite map level: -2
- composite map resolution: 1024

Профили дальности / предзагрузки
================================
Low:    view 4096,  preload 1000, 1 thread
Medium: view 5120,  preload 1000, 2 threads
High:   view 8192,  preload 3000, 2 threads
Ultra:  view 16384, preload 5000, 3 threads

Безопасность теней Android
==========================
Жёсткие ограничения действуют сразу в трёх местах: launcher profile, игровое меню,
и сам RenderingManager перед созданием ShadowManager.

- shadow map resolution: максимум 1024
- maximum shadow map distance: максимум 8192
- в игровом меню доступны только 512 и 1024 для карты теней
- ползунок дальности теней ограничен 8192
- старый settings.cfg с 2048/4096/8192 shadow map автоматически зажимается до 1024
- завышенная дальность автоматически зажимается до 8192

Исправление вылетов при настройке теней
=======================================
На Android структурные изменения ShadowManager (вкл/выкл категорий теней,
размер shadow map, число/конфигурация карт) больше не пересоздают RTT-камеры и
shader defines прямо во время работы через NG-GL4ES. Они сохраняются нормально и
применяются при следующем запуске игры. Дальность тени и параметры фильтрации,
которые безопасны, продолжают обновляться без опасной полной перестройки.

Важно
=====
Desktop-only HDR/Bloom/SSR/SMAA по-прежнему принудительно не включаются этими
профилями. GL4ES texture shrink также не используется.
