# ArenaMW Android Y001s r3

## Y001s r3 — раздел «Помощь»

В лаунчере появился отдельный раздел **«Помощь»** в общем стиле интерфейса: карточки, золотые заголовки и реальные иконки экранных кнопок. Отдельная справка из редактора раскладки удалена. В «Помощи» собраны управление, жесты и удержания, FPS/пресеты, моды/сохранения/хранилище, типовые проблемы и особенности ArenaMW.


Очищенный single-player Android-сборщик ArenaMW для ветки Y001s. По умолчанию используется `pporsilkde/AMW` `main`. Патчи применяются по содержимому и семантическим якорям, а не по номерам строк `@@ -N,+M`.

Patch-stage идемпотентен и рассчитан на изменения desktop `main`: перенос кода выше/ниже сам по себе не ломает patch. Неоднозначный или исчезнувший якорь вызывает остановку сборки для ручной перебазировки. Активирован Android Mali/Magic/VFX stability stage, ранее лежавший вне реальной цепочки.

Основная команда:

```bash
cd buildscripts
./build.sh --arch arm64 --ccache --release
```

Правила сопровождения патчей: `PATCHING.md`.

## Y001s r2 — справка управления и лимит FPS

- Встроенная EN/RU-справка соответствует реальному Android OSC: F11 скрывает/показывает HUD, F12 делает скриншот, Q переключает постоянный бег, удержание «ВЗЯТЬ / E» позволяет манипулировать и перетаскивать предметы. Для ArenaMW отдельно описаны ожидание T и удержание Sneak = Z/меню анимаций.
- В графике доступны **По пресету / 30 FPS / 60 FPS / Без ограничения**. Very Low, Performance и Battery используют 30 FPS; Balanced и Quality — 60 FPS. Ручной лимит не переводит графический пресет в Custom.
