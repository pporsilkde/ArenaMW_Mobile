# ArenaMW Android Y001s r2

## Изменения

- Справка уточнена: F11 скрывает/показывает HUD, F12 делает скриншот, Q включает постоянный бег, удержание «ВЗЯТЬ / E» позволяет манипулировать и перетаскивать предметы.
- В настройки добавлена встроенная «Справка по управлению» с актуальными экранными кнопками, жестами и длинными нажатиями.
- Для ArenaMW отдельно описаны ожидание T, длинное удержание Sneak = меню анимаций, консоль через Journal, F11/F12 и экранная клавиатура.
- В окно графики добавлен лимит FPS: По пресету / 30 FPS / 60 FPS / Без ограничения.
- По пресету: Очень низкие / Производительность / Энергосбережение = 30 FPS; Баланс / Качество = 60 FPS.
- Ручной FPS имеет приоритет и не переводит визуальный пресет в Custom.
- Включает предыдущие Y001s semantic-anchor/MyGUI fixes.
